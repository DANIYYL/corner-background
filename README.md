# corner-background

[![Live Demo](https://img.shields.io/badge/Live_Demo-View_Project-4CAF50?style=for-the-badge&logo=vercel&logoColor=white)](https://DANIYYL.github.io/corner-background/)

## What is this?
 
Modern dark UIs (glassmorphism, SaaS landing pages, portfolios) often use soft glows, blurred blobs and light streaks in the corners of the page. **corner-background** is a small gallery of those effects, built so you can preview them with your own colors and copy the code in one click.
 
## Features
 
- **25 effects**: 15 general backgrounds and 10 small corner-style effects
- **20 ready-made palettes** plus 3 custom color pickers (background, primary, secondary)
- **One-click copy**: click any card and get a ready-to-paste snippet with your chosen colors
- Respects `prefers-reduced-motion`
- Responsive, mobile-safe


## Install
```bash
npm install
npm run dev
```
